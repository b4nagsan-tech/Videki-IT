# b4keyboardwarriors
Ez a b4keyboardwarriors beléptető-programja, készítette *Nagy Sándor Márk* és *Tóth Álmos*.

---

Ez a program egy beléptető rendszer, amiben feljegyezhet minden érkező járművet, vagy személyt, és pontos érkezési idejét.

A program az *b4keyboardwarriors* fő mappán belül az *adatvédelem* mappában található. 
Amikor megnyitja a programot, 3 opció közül választhat, Adatbevitel, Adatbázis megtekintése, és Leállítás. A menüpontok közül számokkal választhat

## Adatbevitel

Ha az adatbevitel menüpontot választja, ki kell választania hogy *járművet*, vagy *személyt* szeretne bevinni a programba. Ezután meg kell adni az új személy/jármű adatait a paramétereknek megfelelően, semmilyen mezőt nem hagyhat üresen.

## Adatbázis megtekintése

Az adatbázis megtekintése megmutatja a felhasználónak a teljes adatbázis tartalmát, úgy ahogyan a fájlban kinéz. Ez hasznos akkor, ha a keresés funkcióval nem találja, amit keres.
